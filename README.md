# Travel Companion V2｜Milestone 1

本版本為「規格與資料基礎版」，不含正式網站程式。

## 內容
- 完整產品規格
- UI 設計規範
- 需求變更紀錄
- 版本說明
- 測試驗收清單
- Osaka 2026 完整旅程資料
- 飯店、交通、必買、票券、行李等獨立 JSON
- JSON Schema
- 資料完整性檢查程式

## 核心原則
1. 程式與旅程資料分離。
2. 更新程式不得覆蓋使用者資料。
3. 唯讀分享模式只顯示「首頁／行程／地圖」。
4. 景點卡片預設只顯示重點，其他資訊以展開方式呈現。
5. 所有正式版本交付前必須通過 TEST_CHECKLIST.md。
